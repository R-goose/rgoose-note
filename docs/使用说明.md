# R-Goose Note 使用说明

适用版本：v1.9.5

R-Goose Note 是一个"白板式"笔记软件。笔记不是一页页从上往下写的文档，而是一块无限大的画布：文字、图片、待办、表格等内容以"块"为单位，想放哪里就拖到哪里，笔记之间还能互相连线、互相引用。

不需要手动保存，所有内容在操作的同时自动存进本地数据库（所以建议安装在D盘，然后在设置中将存储位置也改为D盘）。

## 先认识界面

打开软件后，左侧是导航栏，从上到下依次是：

| 图标 | 名称 | 作用 |
|---|---|---|
| 仪表盘 | 总览 | 查看任务和计划的完成情况统计 |
| 笔记 | 笔记列表 | 浏览、搜索、新建笔记，管理文件夹 |
| 标签 | 标签管理 | 新建标签、改颜色 |
| 素材库 | 图片管理 | 集中存放所有图片素材 |
| 计划 | 待办提醒 | 管理有截止时间的任务，今天有几条会标红提示 |
| 设置 | 设置 | 备份、存储位置、快捷键、AI 配置 |

导航栏下方是文件夹树，可以在里面分门别类放笔记。右下角悬浮的圆球是 AI 助手，可以拖到任意位置。

## 写第一篇笔记

1. 点击左侧导航栏的**笔记**。
2. 点击**新建笔记**按钮，给笔记起个标题。
3. 如果想从现成的版式开始，新建时可以直接挑一个模板。
4. 进入笔记后，看到的是一块空白画布。点顶部工具栏的**文本块**按钮（或按 N 键，或在画布空白处右键选文本），就会出现一个文字块，直接打字。
5. 想再加内容，按 Enter 换行继续写，或者再建新的块。

写完直接关闭即可，内容已经自动保存。

## 画布基本操作

**移动视野**

- 按住**空格键**再拖动鼠标，画布跟着移动。
- 滚动鼠标滚轮上下移动，按住 Ctrl 滚动缩放，Ctrl+0 回到 100%。
- 右下角有一张小地图，显示整块画布的全貌，点一下就能跳到对应位置。

**摆放块**

- 用鼠标按住块拖动，放到任何位置。
- 选中块后按方向键微调位置，按住 Shift 加速。
- 拖动块右下角的手柄改变大小。
- 怕误拖就点块左上角的锁形图标锁定，锁定后不能再拖动。

**多选与对齐**

- 按住鼠标左键在空白处框选，或者按住 Shift 逐个点选。
- 选中两个以上块后，顶部出现对齐工具栏，可以做左对齐、居中、均匀分布等操作。
- 多选后右键选**编为一组**，之后整组一起拖动。

**其他**

- 画布空白处右键，可以快速新建各种类型的块。
- 顶部工具栏可以更换画布背景、开关网格吸附（开启后块会对齐到网格线）。
- 右上角可以切换**只读模式**，防止查看时误改。

## 块的种类和用法

点顶部工具栏的**插入**按钮能看到全部类型：

| 块类型 | 用途 |
|---|---|
| 文本 | 富文本段落，写正文 |
| 图片 | 本地选图，也可以直接 Ctrl+V 粘贴图片 |
| 音频 / 视频 | 插入本地音视频文件 |
| 图片集 | 一次放多张图 |
| 待办 | 带状态、优先级、截止日期的任务，详见下一节 |
| 进度条 | 手动拖动百分比的进度条 |
| 里程碑 | 标题加日期加勾选，标记重要节点 |
| 表格 | 行列表格 |
| 公式 | 输入 LaTeX 语法，实时预览成数学公式 |
| 代码 | 选语言高亮显示，右上角一键复制 |
| 高亮提示 | 提示、警告、危险三种颜色的醒目框 |
| 引用笔记 | 链接到另一篇笔记，详见下一节 |

**设置文字样式**：用鼠标选中一段文字，会弹出浮动工具栏，可以加粗、斜体、下划线、删除线、改颜色、调字号。块内还可以设置列表和标题级别（H1 到 H6）。

**块的通用操作**：右键点块可以创建副本、复制、粘贴、删除。快捷键见文末表格。

## 让笔记互相连接

这是白板笔记最有用的部分，有三种连接方式：

**引用笔记块**：在笔记 A 里插入一个"引用笔记块"，选中笔记 B。之后点击这个块就直接跳到笔记 B。还可以定位到笔记 B 里的某个具体块。

**连线模式**：点顶部工具栏的**连线**按钮（或按 T 键），先点一个块，再点另一个块，两点之间出现连线。也可以直接拖动块左右两侧的连接点去连。双击连线可以加文字说明，悬停连线可以删除。

**反向链接**：画布右下方有一个面板，自动列出"哪些笔记引用了当前笔记"。当你在笔记 B 里引用了笔记 A，回到笔记 A 就能在这里看到笔记 B，点击即可跳过去。

## 整理与查找

**文件夹**

1. 在左侧文件夹树点 **+** 新建文件夹，文件夹可以一层套一层。
2. 双击文件夹名可以重命名；右键可以新建子文件夹、改名、删除。
3. 文件夹上会显示里面有几篇笔记。

**标签**

1. 打开笔记后，在编辑器顶部点标签区域，输入标签名回车，输入不存在的名字会直接创建新标签。
2. 在**标签**页面可以给标签换颜色。
3. 删除标签时，它会自动从所有笔记上摘除，笔记本身不受影响。

**查找**

- 在笔记列表页按 Ctrl+F 聚焦搜索框。
- 任何时候按 **Ctrl+P** 打开命令面板：一处搜索框同时搜笔记、计划、标签、文件夹，还能直接执行"前往某页面""新建笔记"等命令。找不到东西时先按 Ctrl+P。

## 待办与计划

**待办块**（写在笔记里）

插入待办块后可以设置：标题、状态（待办、进行中、已完成、已搁置）、优先级（低中高）、截止日期。点**添加到计划**，这条待办会同步出现在计划页面。

**计划页面**（单独的提醒清单）

1. 点左侧**计划**，新建计划，填写标题、截止时间、优先级，还可以关联一篇笔记。
2. 列表自动分成逾期、今天、全部、已完成四组。
3. 到了时间会弹系统通知（第一次使用会请求通知权限）。
4. 点计划可以直接跳到它关联的那篇笔记。

**任务看板**（在笔记内看任务）

笔记编辑器顶栏有**任务看板**按钮，把当前笔记里的所有待办按状态或优先级分组展示，可以拖拽卡片直接改状态。首页的仪表盘则会汇总所有笔记和计划的任务进度。

## AI 助手

**第一次使用前的配置**

1. API Key：在 AI 服务商（如智谱开放平台）的控制台获取，请勿在文档中明文记录。
2. 打开软件的**设置**页，找到 AI 设置，把 Key 粘贴进去。
3. 点验证，通过后模型列表会自动加载。默认选中的都是免费模型，不花钱就能用。模型推荐这3个，质量最高，当然花费也会多![image-20260817165011901](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20260817165011901.png)

**四种模式**

右下角悬浮球点开就是 AI 窗口，顶部切换模式：

- 对话：问答、润色文字、总结内容、找灵感。支持多个独立会话，可以随时切换。
- 生成图片：输入描述文字，出图后自动存进素材库。
- 生成视频：输入描述，生成耗时较长，等待期间可以点停止。
- 计算器：直接输入算式出结果。

**使用提示**

- 输入框里按 Enter 发送，按 Shift+Enter 换行。
- 生成过程中随时可以点**停止**按钮中断。
- 提示"请求被限流"说明短时间内请求太频繁，等几秒再发。
- 提示"额度用完"或"套餐限制"时，需要去智谱平台查看账户额度。

## 素材库

所有插入笔记的图片都会进素材库，也可以单独上传：

- 点**导入素材文件**上传，支持建文件夹分类存放。
- 点缩略图放大预览。
- 每张图会显示被哪些笔记使用，可以一键跳过去。
- 支持重命名、移动、删除、打标签，搜索框连标签一起搜。
- 可以全部导出，也可以勾选部分导出到本地文件夹。

## 导出与备份

**导出单篇笔记**：在笔记编辑器顶栏点**导出**，可选 PDF、图片、JSON 三种格式。

**备份全部数据**

1. 打开**设置**页的数据管理区。
2. 点**导出数据**得到一个 JSON 文件，包含所有笔记、计划、标签、文件夹。
3. 点**生成备份**得到完整备份包（数据加图片的 zip），最多保留最近 5 份，可以打开备份目录查看。
4. 换电脑或恢复数据时，用**导入数据**选之前的 JSON 文件即可，内容会合并进现有数据。

**数据存在哪**：默认在 C:\Users\你的用户名\AppData\Roaming\r-goose-note。设置页的"文件存储位置"可以改存到别处，软件会自动把数据迁移过去。

## 常见问题

**找不到某篇笔记了**
按 Ctrl+P 打开命令面板，输入标题的几个字，所有笔记、文件夹都能搜到。

**画布缩放乱了，块显示很小**
按 Ctrl+0 重置缩放，或点右下角小地图回到内容区域。

**块拖不动**
两种可能：块被锁定了（点左上角锁形图标解锁），或者当前处于只读模式（关闭顶栏的只读开关）。

**AI 没有反应或报错**
先到设置页检查 API Key 是否填写并验证通过。提示限流就等几秒重试；提示额度问题需要到智谱平台处理。改完设置后重新发送一次消息即可生效。

**换电脑怎么迁移数据**
旧电脑：设置页点导出数据，得到 JSON 文件，同时建议生成一份完整备份。新电脑：装好软件后导入数据，图片素材可以从完整备份包里拿到。

**删除的笔记能找回吗**
删除是直接生效的，没有回收站。重要内容建议定期在设置页生成备份，备份最多保留 5 份。
