第一章 · 编程基础

编程，就是"写指令
让计算机干活"

计算机不会自己思考，只会严格执行人写给它的步骤。编程语言有很多种，核心都是同一件事——把"想做的事"翻译成计算机能懂的指令。

概念 01

源代码

程序员用编程语言写出的文本文件。计算机看不懂，需要被翻译成机器能执行的指令。

概念 02

翻译方式

编译（一次性翻译，如 C/C++）；解释（逐行执行，如 JavaScript）。前端代码属于解释型。

类比

写代码就像给一个特别听话的人写"做事清单"：步骤越清楚，它做得越准。漏写一步，它就原地发呆。

第一章 · 编程基础

数据都长什么样？

计算机底层只认识 0 和 1（二进制）。所有文字、图片、视频，最终都转换成一长串 0 和 1 存起来。

单位含义换算直观感受
bit（位）最小单位，一个 0 或 1—一个开关状态
Byte（字节）基本存储单位1 B = 8 bit存一个英文字母
KB千字节1 KB = 1024 B一小段文字
MB兆字节1 MB = 1024 KB一张手机照片
GB吉字节1 GB = 1024 MB一部高清电影
TB太字节1 TB = 1024 GB一块大硬盘
为什么重要

前端常遇到"图片太大加载慢""文件超过 2MB 上传失败"——本质都是数据体积问题。

第四章 · HTML 详解

HTML：网页的"骨架"

HTML 用"标签"描述网页里有什么内容。标签用尖括号包围、成对出现。

基本语法

开始标签 + 内容 + 结束标签。标签可嵌套，也可带"属性"。

完整网页有固定骨架：html 包着 head（配置）和 body（内容）。

类比

HTML 像人体骨骼——决定有哪些部位，看不出胖瘦美丑。

<!-- 完整网页骨架 --> <!DOCTYPE html> <html lang="zh"> <head> <meta charset="UTF-8"> <title>我的网页</title> </head> <body> <h1>你好，世界</h1> <p>这是段落。</p> </body> </html>

第五章 · CSS 详解

CSS：网页的"外貌"

CSS 决定网页长什么样——颜色、大小、位置、动画。写法："选择器 { 属性: 值 }"。

三种选择器

① 标签：p 选中所有段落

② 类：.card 选中 class 为 card 的元素

③ id：#title 选中 id 为 title 的元素

常用属性

color、font-size、background、margin、padding、border、border-radius

类比

CSS 像人体的皮肤与衣着——同样骨架，穿不同衣服气质完全不同。

/* 标签选择器 */ h1 { color: #ff6b35; font-size: 32px; } /* 类选择器 */ .card { background: #fffaf0; padding: 20px; border-radius: 14px; box-shadow: 4px 4px 0 #2b1a0f; } /* 悬停放大 */ .card:hover { transform: scale(1.05); transition: all .3s; }
11
第五章 · CSS 详解

布局：把元素摆到对的位置

CSS 用布局方案控制排列方式，前端最常用 Flexbox。

盒模型（必须懂）

每个元素都是"盒子"：内容 → padding → border → margin。

Flex 布局

父元素设 display:flex，子元素横向/纵向排列。

justify-content 控主轴对齐，align-items 控交叉轴。

速记

横向排列用 flex，整体居中一行代码

/* 居中 */ .container { display: flex; justify-content: center; align-items: center; height: 100vh; } /* 三栏等宽 */ .row { display: flex; gap: 16px; } .row > div { flex: 1; } /* 响应式 */ @media (max-width: 768px) { .row { flex-direction: column; } }

第六章 · JavaScript 详解

JS：让网页"会思考"

HTML 是骨架、CSS 是外貌，JS 让网页能感知用户操作并做出反应。前端唯一真正的编程语言。

四个核心概念

① 变量：let 存可变数据，const 存不变

② 函数：可复用逻辑，function 或 ()=>{}

③ 判断：if / else，条件分支

④ 循环：for，重复执行

类比

JS 像人体的神经与肌肉——让身体能感知、做反应。

// 1. 变量 let name = '前端'; const PI = 3.14; // 2. 函数 function greet(who) { return '你好，' + who; } // 3. 判断 let age = 18; if (age >= 18) { console.log('成年'); } else { console.log('未成年'); } // 4. 循环 let sum = 0; for (let i = 1; i <= 10; i++) { sum += i; } // 55

第六章 · JavaScript 详解

实战：用 JS 操控网页

JS 最常做的事："用户点了什么 → 改网页内容"。靠 DOM 操作和事件监听实现。

DOM：浏览器把 HTML 解析成"元素树"，JS 可读写节点。

事件：用户操作（点击/输入）触发事件，用 addEventListener 监听。

总结

前端 JS 80% 的工作：选中元素 → 监听事件 → 改内容/样式。

// 1. 选中元素 const btn = document.querySelector('#myBtn'); const box = document.getElementById('box'); // 2. 监听点击 btn.addEventListener('click', () => { // 3. 改内容与样式 box.textContent = '被点了！'; box.style.background = '#ff5d8f'; box.style.transform = 'scale(1.1)'; }); // 监听输入 input.addEventListener('input', (e) => { console.log(e.target.value); });

第八章 · AI 与编程

实战：让 AI 帮你写代码

核心技能是"会提问"——描述越具体，输出越能用。

Prompt 三要素

① 角色：让 AI 当什么（前端工程师）

② 任务：做什么（写卡片）

③ 要求：风格、技术栈、细节

我
你是前端工程师。用 HTML+CSS 写一个奶油色产品卡片，含图片、标题、价格、按钮，圆角、有阴影、悬停上浮。
AI
已生成卡片代码，使用 #fffaf0 底色、14px 圆角、4px 4px 0 硬阴影，transition 实现悬停上浮。
<!-- AI 生成的卡片 --> <div class="product-card"> <img src="cake.jpg" alt="蛋糕"> <h3>草莓蛋糕</h3> <p class="price">¥58</p> <button>加入购物车</button> </div> .product-card { background: #fffaf0; border: 3px solid #2b1a0f; border-radius: 14px; box-shadow: 4px 4px 0 #2b1a0f; transition: all .3s; } .product-card:hover { transform: translateY(-6px); }
提醒

AI 写的代码不是百分百正确，需要你看懂、验证、调整。HTML/CSS/JS 基础不能跳过。
